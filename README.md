A two-line robot confession for make.fun's "The Robot Apology" bounty: one sentence owning a specific mistake — locking its owner out because it secured the front door while the keys were still on the kitchen table — and one sentence naming the lesson that follows from it, moving "keys in hand" to the top of its leaving checklist.

## Run it

```sh
python3 main.py
```

This writes the two lines to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
